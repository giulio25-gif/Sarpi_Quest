# Sarpi Quest

A mobile-first clickable prototype for the StreetGood Visitor Lab project in Milan Chinatown.

## What works

- Home screen and navigation
- Explore checkpoints beyond Via Paolo Sarpi
- Missions grouped into Explore / Reduce / Reuse / Sort
- Simulated QR verification
- Points stored in browser localStorage
- Badges and progress
- Reward redemption with mock redemption code
- Reset Demo button
- 3-step onboarding

## Run locally

Open `index.html` directly in a browser, or run a simple local web server.

## Publish free with GitHub Pages

1. Create a new public GitHub repository, e.g. `sarpi-quest`.
2. Upload `index.html`, `styles.css`, `app.js` and the `assets` folder to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. GitHub will provide a public URL once the deployment is ready.

The app has no backend and no paid dependencies.
